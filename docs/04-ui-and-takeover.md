# Prompt 动画与被接管后的软件变化

## Prompt 文本模型和呈现分离

C-AL 示例固定 600 ms 占位，然后每 33 ms 追加最多 60 字符；仅首次生成或用户“重新生成”触发。它是**已生成文本的呈现动画**，不代表模型正在线生成或正在推理。

始终保存完整 promptModel；动画只更新显示缓冲。复制 / 用户开始编辑时立即显全，并取消所有旧 timer；复制的是完整 Prompt 或当前用户编辑版，不是半截缓冲。隐藏时暂停呈现，恢复后继续；关闭动效 / prefers-reduced-motion 直接显全。新会话 / 新版本使旧动画失效，poll 不重复启动显字。

用户手工编辑后保留内容，不因 log / inspect 刷新覆盖；会话轮换导致过期时禁用复制并提供重新生成。只读字段由 Core 检查：在 Prompt 中删掉限制不获得额外权限。

[Qt 示例](../examples/qt_prompt.py) 展示 timer、批量 insertPlainText、完整复制、编辑中止、隐藏暂停与资源释放。[Web 示例](../examples/local_agentlink/web/app.js) 包含同样的文本模型分离与系统动效偏好。

## 被控制后的可观察变化

| 阶段 | 软件应呈现的变化 | 当前示例 |
| --- | --- | --- |
| 等待 | Prompt / Log 双栏，当前工程与会话，等 Agent 提示 | 完整可复制合同，清晰等待状态 |
| identify | 实际 Agent 名、全局接管标识、工作边框 | 顶部身份与状态边框；不猜模型名 |
| 执行 | 操作摘要、真实百分比或不定进度 | authoritative active 状态驱动动画，断开立即停 |
| apply | 工程对象、时间线 / 库、标题 / 修改状态刷新 | projectRevision 触发真实片段刷新，附 runId，保留用户数据 |
| evaluate / preview | 最终混合 / 领域结果；暂切页面或帧后还原 | 由实际软件 adapter 实现，读操作与写操作分开 |
| finish | 完成条件通过后停止工作动效、给重载入口 | 检查实际片段，手动“重载结果” |
| cancel / disconnect | 阻断后续写入，明确取消 / 断开，保留已提交结果 | CLI 写入被拒绝，GUI 停动效 |
| undo | 只撤回本次未被修改的业务对象，冲突报错 | 按 runId 检查完整片段记录，不删除用户后续编辑 |

完整桌面接入可以增加彩虹窗口边框、低透明度代码词背景、完成按钮短暂呼吸提示。若需要完成后自动重载，可采用 3 秒无交互倒计时，鼠标 / 键盘 / 滚轮交互重新计时；先检查未保存内容，在确实安全时才重载。当前示例提供手动重载，未实现自动倒计时。

UI 不应在接管时全面锁死。锁住会话 / 工程 / 范围等会改变任务目标的控件；保留取消、日志浏览与必要检查。并行人工编辑应通过版本冲突处理，不能静默覆盖。

## 动效与无障碍

边框 / 代码词背景只装饰，不截获鼠标，不影响文本阅读。页面 / 窗口隐藏暂停连续动画，但状态同步按低频继续。终态静止，完成短提示不随 poll / 切 tab 重播。系统减少动效与软件开关同时生效。错误、状态和进度有文本，不能只靠颜色；Prompt 可选中，按钮有标签，Log 不逐条屏幕阅读器播报稠密事件。

Qt 生产接入将系统动效设置映射到组件的 set_motion_enabled，并在 window minimize / app deactivate 时暂停装饰 timer。示例 Qt 组件只接收应用传入的动效开关；不宣称自动检测所有平台的系统设置。
